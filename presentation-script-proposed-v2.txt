READ THIS FIRST — EDITORIAL NOTES, NOT SPOKEN

This is a complete alternative performance script. It proposes a new run
order and new audience copy. It is not synchronized with the current app.
The existing presentation-script.txt and application are unchanged.

Only the text under NARRATION is spoken. ON SCREEN is audience copy.
PICTURE / DELIVERY describes staging and pauses. VISUAL CHANGE identifies
work needed to make the proposed words true on screen. SOURCE lists existing
beat IDs for comparison; V2 numbers are new editorial references, not app IDs.

There are 47 proposed beats. Many contain a continuous animation assembled
from several existing beats. Fewer clicks should not mean faster animation.
All old durations need to be replaced after a spoken rehearsal; this draft
does not assign artificial cinema clocks to prose that has not been timed.

Timing guide: approximately 2,826 spoken words, excluding parenthetical
delivery directions. That is about 19.5–21.7 minutes of speech at 145–130
words per minute, before silence, animation holds, and audience response.
Budget roughly 23–26 minutes for an initial rehearsal, then measure it.
This is an estimate, not a verified runtime.

The argument:
Specialized parts gain capabilities through coordination. An enterprise
already depends on that coordination. An agent operating within it needs
a usable representation of relationships, current evidence, commitments,
and authority. Obtaining evidence and carrying out decisions depends on
communication across systems. Those dependencies belong inside the design
and evaluation of the intelligent system.

The opening uses natural systems as an invitation to notice relationships.
It does not claim that every network is intelligent or that similar-looking
graphs prove identical mechanisms. The enterprise example earns the
operational conclusion.

Two deliberate story changes to review:
1. The enterprise model is explained before the agent uses it.
2. The aircraft example concerns an operations agent preparing and submitting
   a route amendment within delegated authority. It does not claim that an
   LLM pilots an aircraft. Flight execution and clearance remain with the
   appropriate flight systems and authorities. This narrows the original
   “no one in the seat” premise so the network argument stays in focus.

The logistics company, shipment, cargo constraint, and agent workflow are
illustrative. No measured business result or deployed autonomous-flight
capability is being claimed. Any dates, names, attribution, or recognizable
sports sequence retained from the original should receive the normal final
fact and rights check before public use.

V2 BEAT 24 — Facts, promises, permission
SOURCE: auto-semantics

ON SCREEN
What is true?
What is promised?
What is allowed?

PICTURE / DELIVERY
Reveal these three short questions sequentially beside the relevant parts

NARRATION

A useful enterprise model preserves those distinctions. Otherwise a
plausible plan can quietly assume a permission it was never given.

VISUAL CHANGE

the narrator supplies the examples while the picture locates them.

V2 BEAT 32 — The job has a deadline

ON SCREEN

NARRATION

NARRATION

Designing the job means deciding which nodes can participate, what context they exchange, how long they can wait, and how they recover when an answer does not arrive. Who is allowed to act? Which systems must agree before the work can proceed?
